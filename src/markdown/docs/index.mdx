BrutalizmUI is an open-source library of neobrutalism-styled React components built with Tailwind CSS 4 and Shadcn/ui. It provides developers with a collection of bold, high-contrast, and accessible UI elements designed for rapid prototyping, focusing on developer ownership through a copy-paste architecture.

## What is Neobrutalism in Web Design?

Neobrutalism is a mix of regular brutalism in web design and more modern typography,
illustration, and animation standards. Neobrutalism refuses the usual components
of UX-UI design and embraces uncomfortable design elements, and it is more fearless
to use distinctive color palettes.

## Why Use BrutalizmUI?

I created this collection of components for people who want to learn more
about neobrutalism style and to help them get started with creating neobrutalism
layouts. By using BrutalizmUI, you gain access to a set of highly customizable primitives that prioritize developer ownership and design flexibility.
